# Contributing to OpenScratch

Contributions are welcome! By contributing to OpenScratch, you agree that your contributions are released into the public domain under [The Unlicense](./UNLICENSE).

## Helpful Areas
- New built-in vector/SVG sprite presets and sound synthesis patches (`src/engine/coreRuntime.js`, `src/data/assets.ts`)
- Additional natural-language phrase patterns (`src/engine/openscript.ts`)
- New starter templates across games, animations, and websites (`src/data/templates.ts`)
- Accessibility and mobile/touch block interactions (`src/components/`)

## Checks Before Opening a PR
```bash
npm run test:run
npm run build
```
